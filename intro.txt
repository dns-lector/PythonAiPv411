Встановлення оточення.
1. Python-3.13.13 (на даний момент не всі модулі сумісні з Python-14)
2. Створюємо локальне оточення Python:
   > C:\Python\Python313\python.exe -m venv .venv
3. Активуємо оточення (якщо не включилось автоматично).
   При включеному оточенні промпт термінала містить його назву (.venv)
   > ./.venv/Scripts/Activate.ps1
  за потреби виходу (деактивації) пишемо
   > deactivate 
4. Встановлюємо пакети (При включеному оточенні)
   > pip install jupyter
    > pip install numpy
4.1. Збираємо дані про всі підключені пакети 
   > pip freeze > deps.txt    
   це дає можливість у подальшому замість окермого встановлення 
   пакетів один за іншим зазначити файл з їх переліком
   > pip install -r deps.txt
5. Запускаємо робочий сервер
   > jupyter notebook
   або 
   > jupyter lab
